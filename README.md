Project Description:
    The program is a calculator that uses a Read-Evaluate-Print Loop (REPL) pattern. It accepts user input and performs a function based on that input. This is done by reading the input, evaluating it, and then printing it. This process loops until the user stops it, which is how the REPL pattern got its name. This calculator can perform addition, subtraction, multiplication, and division. It can also calculate power, root, perform integer division, find absolute difference, and calculate percentage. These calculations are saved or loaded to a file using pandas. They can also be displayed by the calculator. Any calculation can be undone or redone. There is also a help function for people to use and a way to gracefully exit the calculator
